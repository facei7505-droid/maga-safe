## Перед питчем

1. Ключ Claude в Render → Environment → `ANTHROPIC_API_KEY` (если хотим показать арбитра).
2. В логе сборки Render строка «модель для прода поставлена: …, реальных постов: 1639».
3. `PRUF_TOKEN=… python scripts/warmup.py --keep-awake 120` за 10 минут до выступления: все шаги ✓.
4. На питче — кнопка «▶ Демо-тур» в дашборде: сценарий идёт сам, с подписями.
5. На телефоне открыт бот: переслать скам-пост, показать кнопку «Это не мошенничество».
