# Кейс SafeNet KZ: кратко

**Задача:** MVP, который находит в соцсетях и мессенджерах Казахстана признаки незаконных схем, ставит риск (низкий / средний / высокий) и объясняет, почему.

**Обязательно:** русский и казахский, транслит и сленг, причины и уровень риска на каждом случае, минимум ложных срабатываний на обычных конкурсах и легальной рекламе, только открытые или синтетические данные. Мультимодальность (скриншоты, эфиры) даёт плюс.

**Сдать:** работающий MVP, питч на 5 минут, описание методики (признаки и расчёт риска), метрики precision / recall / FPR на тесте, план внедрения.

| Критерий | Вес |
|---|---|
| Точность на тестовых данных | 30% |
| Объяснимость («признаки, а не вердикты») | 20% |
| Инновационность (мультимодальность, граф) | 20% |
| Практичность для аналитика | 15% |
| Масштабируемость | 10% |
| Презентация | 5% |

**Подход:** одна платформа на три трека: нормализация (OCR, Whisper, транслит, раскрытие ссылок) → правила + LLM-экстрактор + классификатор на эмбеддингах + граф связей → балл 0–100 с обязательными сочетаниями признаков и стоп-признаками → дашборд аналитика.
