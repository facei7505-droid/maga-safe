## Что говорить, если спросят «это реальные данные?»

- Цифры качества (precision 0,92, recall 0,83 на real_v4) — на **реальных** постах из каналов, которые система раньше
  не видела, обезличенных; метки ставили два независимых ИИ-разметчика.
- Демо — **придуманные** каналы и номера, чтобы не показывать на экране настоящих людей; логика та же.
- Разведчик на демо идёт по вымышленной сети; на живом Telegram — тот же код, только источник другой.
- Проверка разметки человеком — готовый инструмент, раунд с экспертом партнёра — следующий шаг.
