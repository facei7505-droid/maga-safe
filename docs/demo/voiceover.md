# Демо ПРУФ: сценарий озвучки

Видео: [`pruf-demo.mp4`](pruf-demo.mp4), 1920×1080, 3 минуты 5 секунд, без звука. Время шагов — в [`pruf-demo.timeline.json`](pruf-demo.timeline.json); пересобрать видео: `python scripts/record_demo.py` (см. docstring).

Читать спокойно, примерно 120–130 слов в минуту. Текст в каждом блоке рассчитан на его длительность; если не успеваете, сокращайте фразы в скобках.

## Цифры, если спросят

- Самый новый и трудный слепой набор v12 (200 постов, написан отдельным агентом без доступа к коду, половина — трудные легальные посты): precision 0,88, recall 0,88, ложные тревоги 12% — правила + ML, без Claude.
- Предыдущий набор v11: precision 0,94, recall 0,85, ложные тревоги 5% — правила + ML, без Claude.
- С Claude в спорной зоне (набор v10): recall около 0,87 при той же точности.
- Реестр пруфов: почти-дубликаты картинок (PDQ + OCR), текстов (MinHash), реквизитов и ссылок.
