# maga-safe · SafeNet KZ

Прототип для хакатона SafeNet KZ (Шымкент, 2026): поиск признаков незаконных схем в соцсетях и мессенджерах Казахстана.

- **Трек 1, «Розыгрыши под контролем»:** платные лотереи и розыгрыши.
- **Трек 2, «Скрытая игра»:** скрытая реклама онлайн-казино.
- **Трек 3, «Стоп-пирамида»:** финансовые пирамиды в WhatsApp/Telegram.

Система не выносит вердикт, а показывает **признаки** нарушения с цитатами и уровнем риска (низкий / средний / высокий), а решение принимает аналитик. Подробнее см. [docs/case.md](docs/case.md).
