ППРУФ признаки схем и повторные «пруфы»

    Клавиши: j/k — следующий/предыдущий кейс, / — поиск, Esc — закрыть.

    Выберите кейс в очереди слева.

    Примеры:

    Проверка реквизита банком

    Значение не сохраняется. Ответ — признаки для проверки, а не основание для блокировки.

    Лента реквизитов, засвеченных в постах со средним и высоким риском (то же, что получает банк по API).
