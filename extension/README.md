# ПРУФ Sentinel

Расширение Chrome (Manifest V3) — тонкий клиент к серверу ПРУФ.

## Установка

1. Запустите сервер ПРУФ (см. корневой README), например `http://127.0.0.1:8000`.
2. `chrome://extensions` → включите «Режим разработчика» → «Загрузить распакованное» → выберите эту папку.
3. Нажмите на значок расширения → «Подключение к серверу ПРУФ»: адрес сервера и токен из `PRUF_EXTENSION_TOKENS`
   (в режиме `PRUF_DEV_MODE=1` токен не нужен) → «Сохранить».

## Что делает

| Файл | Роль |
|---|---|
| `lib/extract.js` | реквизиты (телефон +7, карта с проверкой Луна, IBAN KZ, ссылка Kaspi), ссылки, 11 признаков схем, SHA-256 текста |
| `content.js` | MutationObserver на Telegram Web и Instagram; для нового поста считает признаки и, если риск ≥ 65, рисует плашку в Shadow DOM с кнопкой «Почему?» |
| `background.js` | запросы к API (токен хранится только здесь), чёрный список доменов раз в час в правилах `declarativeNetRequest`, пункт меню «Проверить в ПРУФ», счётчики |
| `warning.html` | страница вместо сайта из чёрного списка; «Всё равно перейти» разрешает домен до конца сессии |
| `popup.html` | сколько постов проверено, сколько угроз найдено, сколько сайтов остановлено; настройки подключения |

## Приватность

- Текст поста не покидает браузер. На `POST /api/v1/inspect` уходят только реквизиты, ссылки, SHA-256 нормализованного
  текста и номера сработавших признаков. Сервер ничего из этого не сохраняет.
- Посты без реквизитов, ссылок и признаков не отправляются совсем.
- Буфер обмена расширение не читает. «Проверить в ПРУФ» отправляет только выделенный фрагмент (до 200 символов, из него
  берётся реквизит). Номер карты нужен серверу целиком, чтобы сравнить его HMAC с реестром; он не хранится.
- Ответ про реквизит: «засвечен в схемах или нет» и треки, без числа постов и каналов.

## Разрешения

- `host_permissions: <all_urls>`: перенаправление на страницу-предупреждение (`redirect` в declarativeNetRequest) требует
  доступа к адресу, который перенаправляется. Скрипт на страницы ставится только на `web.telegram.org` и `www.instagram.com`.
- `notifications`: результат «Проверить в ПРУФ». `alarms`: обновление чёрного списка раз в час. `contextMenus`, `storage`.
