# Модель для прода

Здесь лежит ML-модель, обученная **и на реальных постах** (`eval/real_v*.jsonl`). Сами посты в git не попадают,
поэтому без этой папки Docker на Render обучает модель только на синтетике и ручных наборах, и она слабее,
чем в замерах `docs/metrics.md`.

Как обновить (там, где лежат реальные посты):

```bash
python scripts/gen_synthetic.py
python scripts/train.py --publish        # откажется, если какого-то набора из DEV_SETS нет в eval/
git add models/prod/clf.joblib models/prod/clf.json && git commit -m "chore: production model with real posts"
```

`clf.json` — манифест: SHA-256 модели, версия scikit-learn, наборы и число примеров, сколько реальных постов.
При сборке `scripts/install_model.py` ставит модель, только если хэш сошёлся, версия scikit-learn та же
(major.minor: pickle между версиями не переносим; поэтому в requirements.txt версия закреплена) и модель предсказывает. Иначе сборка обучает модель сама,
причина видна в логе сборки.

Что внутри модели: TF-IDF по символьным 2–5-граммам с `min_df=2` и логистическая регрессия. Кусок текста
попадает в словарь, только если встречается хотя бы в двух постах; восстановить пост из модели нельзя.
Посты перед этим обезличены (`scripts/anonymize_real.py`).
